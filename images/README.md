# Images folder structure

```
images/
├── brand/              # Logo & shared brand assets
│   ├── Title_Image.png # Favicon & header logo
│   └── LogOut.png      # Admin logout icon
├── auth/               # Auth & feedback assets
│   └── tick.png        # Success/confirmation icon (e.g. after register)
├── contact/            # Contact page assets
│   └── Contact.gif
├── Home/               # Home page assets
│   ├── Header/         # Search, Cart, User icons
│   ├── Categories/      # Category icons (Grocery, Mobiles, etc.)
│   ├── Arrivals/       # New arrivals images
│   ├── Offers/         # Offer banners
│   ├── Home_Banner.jpg
│   ├── Home_Services.png
│   ├── Home_Recom_1.png
│   └── Home_Recom_2.png
├── Products/           # Product images (Prod-1.jpg … Prod-31.jpg)
└── misc/              # Unused / archive assets
    ├── category-icons/ # Alternate category icons (i-cate1–8)
    └── …               # Other legacy/screenshot assets
```
